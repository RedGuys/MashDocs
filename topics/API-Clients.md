# API Клиенты

Немного клиентов и библиотек для работы с API school.mos.ru и не только. Если вы тоже разрабатываете клиенты для работы с API school.mos.ru, не бойтесь кидать MR с добавлением вашего клиента.

* [DnevnikAPI (node.js)](https://github.com/RedGuyRu/DnevnikApi) — Библиотека от автора этого документа, в связи с выпуском из учебного заведения поддержка почти отсутствует.
* [DnevnikAPI (Python)](https://github.com/RedGuyRu/DnevnikApiPython) - Официальный порт DnevnikAPI для Python, также не очень поддерживается автором.
* [OctoDiary-py (Python)](https://github.com/OctoDiary/OctoDiary-py) - Чуть более поддерживаемая библиотека для Python.
* [OctoDiary-kt](https://github.com/OctoDiary/OctoDiary-kt) - Клиент для Android на Kotlin, активно поддерживается.
